# 霓虹打磚塊 · NEON BREAKER

以 HTML、CSS 與原生 JavaScript 製作的霓虹風格打磚塊網頁遊戲。接住掉落道具、調整反彈角度，挑戰更高的通關紀錄。

[線上遊玩](https://neon-breaker-arcade-ly-1103.yue-shi-lee.chatgpt.site/)

> 線上版本目前採私人存取設定，需要具備存取權的帳號才能開啟。原始碼可自行在本機執行或部署至 GitHub Pages。

## 遊戲功能

- 每局有 3 條生命，所有球落出場地時扣除 1 條生命。
- 清空關卡中的所有磚塊即可通關，每通關加 1 分。
- 後續關卡逐步提升球速、增加磚塊硬度，並改變磚塊排列；磚塊上的數字代表剩餘耐久度。
- 部分磚塊擊碎後會隨機掉落道具，使用板子接住即可生效。
- 板子不同位置會產生不同的反彈角度。
- 支援暫停、繼續、重新挑戰及音效開關。
- 支援電腦與手機操作，最高分自動儲存在瀏覽器。

## 道具

| 道具 | 效果 | 持續時間 |
| --- | --- | --- |
| 多重球 ✣ | 增加 2 顆球，場上最多 9 顆 | 直到球掉落或關卡結束 |
| 加寬板子 ↔ | 增加接球範圍 | 15 秒 |
| 加速球 » | 球速變為一般速度的 1.35 倍 | 12 秒 |
| 減速球 « | 球速變為一般速度的 0.72 倍 | 12 秒 |

重複接到限時道具會重設該效果的倒數時間；加速與減速效果會互相取代。切換關卡或失去一條生命時，限時效果會重設。

## 操作方式

| 操作 | 方法 |
| --- | --- |
| 移動板子 | 移動滑鼠、左右方向鍵、A / D，或在遊戲場地拖曳 |
| 發球 | 空白鍵，或點擊／觸碰遊戲場地 |
| 暫停／繼續 | P 鍵，或遊戲上方的暫停按鈕 |
| 開始／重新挑戰／下一關 | 畫面中央按鈕 |
| 切換音效 | 右上角音效按鈕，預設關閉 |

視窗失去焦點或切換分頁時，進行中的遊戲會自動暫停。

## 本機執行

此專案不需要安裝套件或執行建置。下載或複製專案後，以現代瀏覽器開啟 `dist/index.html` 即可遊玩。

建議透過本機 HTTP 伺服器取得較一致的瀏覽器儲存行為。若已安裝 Python，可在專案根目錄執行：

```sh
python -m http.server 8080 --directory dist
```

接著開啟 [http://localhost:8080](http://localhost:8080)。

字型使用 Google Fonts；離線時會使用系統備用字型，遊戲本身不依賴外部套件。

## 專案結構

```text
neon-breaker/
├── README.md               # 專案說明
├── check.cjs               # 遊戲邏輯檢查
├── dist/
│   ├── index.html          # 網頁結構與操作介面
│   ├── style.css           # 霓虹風格與響應式版面
│   └── game.js             # 遊戲迴圈、碰撞、道具與紀錄
└── .openai/
    └── hosting.json        # Sites 部署設定
```

## 邏輯檢查

若已安裝 Node.js，在專案根目錄執行：

```sh
node check.cjs
```

檢查涵蓋發球、四種道具、通關計分、最高分儲存、難度提升、暫停與遊戲結束。此檢查以模擬環境執行，不涵蓋實際瀏覽器畫面與操作驗證。

## 最高分儲存

最高分使用 `localStorage` 儲存，鍵名為 `neon-breaker-best`。

- 紀錄只保存在目前瀏覽器與網站來源中，不會同步至帳號、其他裝置或 GitHub。
- 更換網址、瀏覽器或裝置時，會使用各自獨立的紀錄。
- 清除網站資料會移除紀錄；無痕模式或封鎖儲存時，紀錄可能無法保留。

## 部署至 GitHub Pages

此專案是純靜態網站，可使用 GitHub Pages 部署。

若採用從分支部署的方式，可將 `dist` 內的三個檔案放到儲存庫根目錄，或放入根目錄的 `docs` 資料夾，再於 GitHub Pages 設定選取對應的發布資料夾。若保留目前的 `dist` 結構，則需自行設定部署流程，以 `dist` 作為發布內容。

`.openai/hosting.json` 僅供原本的 Sites 部署使用，GitHub Pages 不需要此檔案。

## 技術

- HTML5 Canvas：場地繪製、球與磚塊動畫
- 原生 JavaScript：遊戲邏輯、鍵盤與指標操作
- CSS：響應式版面與視覺樣式
- Web Audio API：簡易遊戲音效
- localStorage：本機最高分紀錄
